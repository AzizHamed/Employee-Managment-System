# 👥 Employee Management System

A full-stack **Employee Management System** built with **React** and **Spring Boot**.

The application provides a simple interface for managing employee records while demonstrating full-stack development, REST API integration, and communication between a React frontend and Spring Boot backend.

## ✨ Features

### 👥 Employee Management
- View employee records
- Add new employees
- Update existing employee information
- Delete employee records

### 🔄 Full-Stack Integration
- React frontend connected to a Spring Boot backend
- RESTful API communication between client and server
- Dynamic employee data retrieval and updates

## 🌐 REST API

The backend exposes RESTful endpoints for managing employee records.

The application supports the main CRUD operations:

| Operation | Description |
|---|---|
| **Create** | Add a new employee |
| **Read** | Retrieve employee records |
| **Update** | Edit existing employee information |
| **Delete** | Remove an employee |

## 🏗️ Architecture

The project follows a client-server architecture:

```text
React Frontend
      │
      │ HTTP / REST API
      ▼
Spring Boot Backend
      │
      ▼
Employee Data
```

The frontend is responsible for displaying and managing the user interface, while the Spring Boot backend handles employee-related operations and exposes them through REST APIs.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- **Node.js**
- **npm**
- **Java**
- **Maven**

### Clone the Repository

```bash
git clone https://github.com/AzizHamed/employee-management-system.git
```

```bash
cd employee-management-system
```

### Run the Backend

Navigate to the Spring Boot backend directory:

```bash
cd backend
```

Run the application:

```bash
mvn spring-boot:run
```

### Run the Frontend

Open another terminal and navigate to the frontend directory:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the React application:

```bash
npm start
```
